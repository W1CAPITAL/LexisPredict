LEXISPREDICT - AUXILIAR PJE LOCAL (GRATUITO)
Versao 0.1.0 - assistente do navegador Chrome desktop

INSTALACAO
1. Descompacte este arquivo ZIP numa pasta de sua escolha.
2. No Chrome, abra chrome://extensions.
3. Habilite "Modo do desenvolvedor".
4. Clique "Carregar sem compactacao" e selecione a pasta descompactada.
5. O navegador instala a extensao gratuitamente.

COMO USAR
1. Entre no PJe do tribunal com o certificado OAB (PJeOffice Pro).
2. Abra os autos digitais do processo desejado.
3. Clique no icone LexisPredict da extensao no Chrome.
4. Se ainda não estiver autenticado, selecione o botão OFICIAL de entrada com certificado.
   O PJeOffice Pro, VIDaaS Connect, Bird ID Desktop ou certificados A1/A3
   configurados no computador farão a seleção/autorização, se compatíveis.
5. Com os autos abertos, acione a opção de download oficial identificada.
6. Se o PJe abrir outra janela, escolha TODOS os documentos e confirme nela.
7. Baixe o PDF/ZIP oficial e importe-o no scanner LexisPredict, modo gratuito.

LIMITES
- A extensao NAO entra no tribunal por conta propria; o advogado autentica a sessao.
- Ela apenas aciona controles existentes na pagina, se forem identificaveis.
- Apos clicado um controle, ainda pode ser necessario escolher documentos no portal.
- As interfaces variam por tribunal; o assistente pode nao localizar o comando.
- Nao realiza acesso a processos sigilosos sem autorizacao do advogado.
- Nao le certificado, PIN, senhas, cookies, nem envia documentos ao LexisPredict.
- Nao faz envio ou peticionamento automatizado.
- O sistema pode gerar arquivos PDF unicos, que nao podem ser cortados em pecas com este auxiliar.
