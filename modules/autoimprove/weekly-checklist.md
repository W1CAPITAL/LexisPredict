# Checklist semanal autoimprove

## Dia fixo (ex. sexta 30 min)

1. Recall vault: tags `falha`, `gtm`, `router`
2. Exportar ou colar log de intents da semana em `runs/`
3. `python3 scripts/score_week.py runs/semana.txt`
4. Escolher **1** item:
   - bug P0 Lexis → codigo
   - intent caro demais → router
   - copy fraca → gtm + humanizer
5. Patch minimo + eval.md
6. Capture decisao no vault
7. Opcional: 3 comentarios LinkedIn com hook vencedor

## Sinal de que o loop funciona

- % zero-token sobe mes a mes
- Menos mensagem "numero errado" de usuario
- Mesmo pitch GTM com mais visita a perfil
